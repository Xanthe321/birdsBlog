# Avian Chronicles

Modern ve etkileyici bir kuş gözlem ve fotoğrafçılık blogu.

## Özellikler

- Duyarlı ve modern tasarım
- SEO dostu Türkçe içerik
- Kuş fotoğrafları galerisi
- Blog makaleleri
- İletişim formu
- Karanlık/Aydınlık tema desteği

## Teknolojiler

- Next.js 13
- TypeScript
- Tailwind CSS
- Shadcn/UI
- Lucide Icons

## Geliştirme

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Üretime hazırla
npm run build
```
